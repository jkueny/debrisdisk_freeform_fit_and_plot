# Freeform pipeline testing with RDI mode
#### RDI mode now functional and running fast.
+ Fixed a bug where the disk model was being L2 normalized and hp filtered before convolution.
  - This is what was causing the small amplitude disk ghost in the residuals.
+ This mode is significantly faster than ADI mode
  - Next steps are to drastically upsize the RDI datasets for higher S/N
+ Disabled training update plots because it was the performance bottleneck in this script.
#### Regularization should be simple rather than complex.
+ Residual disk penalty disabled.
  - This was computed using a high-pass filtered version of the reference disk model.
    + Then all significant nonzero pixels were set to unity.
    + This reference disk spine was convolved with the residuals map and the peak value
    added to the loss.
  - This penalty was causing the optimizer to allow a large oversubtraction feature
  at the forward minor axis of the disk to lower the loss, as opposed to removing the
  faint trace of the disk in the residuals.
+ Asymmetric weights disabled
  - This used a tanh function (could have also used sigmoid) to asymmetrically weigh
  positive over negative values about zero.
  - This was tried out because of the aforementioned bug and there appeared to be a
  negative halo that was enforcing a small positive amplitude to compensate.
+ Positivity constraint
  - Keep this, it safeguards against non-physical models and high frequency stuff.
+ High-spatial frequency penalties using a reference disk model PSD
  - This works very well using only fitted elliptical Gaussian window functions to
  the reference model PSD.
    + Unknown how well this works if the disk model isn't already a pretty good fit.
  - Currently some "orange peel" texture still gets in to the optimized models.
    + Unsure how to improve this, currently.
+ Keep noise map to use as the weights for the loss calculation.
  - Variance map penalizes the minor axis too heavily.

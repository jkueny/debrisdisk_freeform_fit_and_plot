# Fitting the SPF to the freefrom disk models
### Regularization
+ For the current regularization configuration, lambda reg values are typically in the range of 0.2 to 0.5
  - $\lambda = 0.1$ leads to no residuals, but fits ADI artifacts and speckles and WDH noise.
  - $\lambda = 0.2$ leads to very little residual disk, but fits some ADI artifacts and speckles and WDH noise.
  - $0.3 < \lambda < 0.5$ leads to residual disk within the S/N~1 level, but ignores ADI artifacts and speckles.
    + Very dependent on S/N of the disk in the KLIP image.
+ Current configuration:
  - Penalize excess power in the PSD of a given reference disk model.
    + Optimized elliptical Gaussian window function fit to the reference model PSD
    + Generously scale the window by the max value of the reference PSD
    + Add the reference PSD on top of this window for penalty "armor" for the lowest spatial frequencies.
  - Penalize residual disk structure
    + High-pass filter the *same* reference disk used for the reference PSD to isolate the disk spine
    + Assign all values to 1 for a binary image of the disk spine.
    + For each iteration, convolve the residuals image by the disk spine and add the max value
    in the convolution map to the loss.
      - Scale the max value by 10 times $\lambda_{reg}$
      - Normalize the convolution map with an L2 norm.
